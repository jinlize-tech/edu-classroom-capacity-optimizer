# 教室产能与满班率优化领域指南

## 业务问题

教室看似排满，但黄金时段忙、非黄金时段空，班容和课程结构未优化，资产利用率被高估。

## 产品解决方案

按时间段、教室、课程和教师分析产能与满班率，生成编排情景和释放/扩班建议。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `rooms` | 教室清单 | 是 | 教室编号、容量和可用时段 |
| `open_hours` | 每周开放时段 | 是 | 按星期和起止时间 |
| `classes` | 现有班级 | 是 | 教室、时段、人数、容量、课程和教师 |
| `period` | 分析周期 | 是 | 周或学期 |
| `demand_assumptions` | 需求假设 | 否 | 新增或迁移需求，须标明假设 |
| `capacity_rules` | 容量与使用规则 | 是 | 不得超员、设备限制等 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

需求预测不确定；不能只看满班率忽略教学质量；硬约束需人工确认。
